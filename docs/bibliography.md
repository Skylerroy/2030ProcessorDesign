# 参考文献

本书共引用 20 条文献，涵盖处理器体系结构、微架构、RISC-V 指令集、VLSI 电路以及经典教科书五个主题。条目按作者姓氏首字母排序；每条结尾的锚点支持从正文 `\cite{key}` 位置直接跳转定位。

参考文献格式接近 GB/T 7714，但考虑到 Web 阅读体验作了若干简化：书籍标题用斜体，期刊和会议论文集用斜体，作者多于三人时以 _et al._ 缩写。
