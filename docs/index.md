## 阅读路径建议

不同背景的读者可以选择不同的阅读路径，本书每一篇都是相对独立的模块，章末的"前置依赖"会提示需要的基础。

- **完全新手（本科高年级、刚接触体系结构）**：从[第 1 章](/part1/ch01)线性阅读，重点跟完第一篇和第二篇，先把"流水线 + Cache 层次"这一核心直觉建立起来。书里每个关键概念都会先用一个极简示例说明，不必担心一步跨不过去。
- **已掌握经典流水线（读过 *Computer Architecture: A Quantitative Approach* 或同等教材）**：可以快速浏览第一篇校准术语，然后直接从[第五篇 乱序执行引擎](/part5/ch24)读起；这是本书最核心、最见功力的部分。
- **工业界研发工程师（做 RTL、验证、性能分析的同行）**：推荐先看[第六篇 真实世界的处理器](/part6/ch40)，带着自己熟悉的产品去反向对照；再回来按需补齐特定机制的背景。
- **芯片架构/系统方向的研究者**：建议直接跳至[第八篇 先进处理器发展](/part8/ch49)，本书在 CXL/UCIe/安全/AI 集成等方向给出了工业界与学术界最新方案的系统性梳理。
- **只想解决一个具体问题**：用右上角搜索框全文搜中文关键词，每一章的小节粒度非常细（通常一个硬件机制对应一节），定位很快。

如果你对某一篇的某一章犹豫"是否是我要看的内容"，可以先看该章引言末尾的 "本章回答的问题" 列表。

## 如何使用本书

- **从头读起**：如果你是处理器设计的入门者，建议从[第 1 章](/part1/ch01)线性阅读。
- **查阅特定主题**：用右上角的搜索框，本书支持全文中文搜索。
- **查看参考文献**：每章末尾引用的文献会汇总在 [参考文献](/bibliography) 页。
- **勘误反馈**：发现错别字或事实错误，欢迎到 GitHub Issues 反馈。
